# Knowledge base

What Ben is, how he works, what he is building, and what has already been decided. Read by the `advisor` agent, written by it, and editable by hand by Ben.

## Files

| File | Holds |
| --- | --- |
| `profile.md` | The person: environment, taste, working style, what he likes and dislikes |
| `principles.md` | The rules his decisions already follow, and how to apply them |
| `projects.md` | What is being built and where each thing stands |
| `ideas.md` | The idea log: what was proposed, what was decided, what to revisit |

## Rules for what goes in

- One fact per line, with the date it was learned.
- A fact that changed is marked superseded and dated. Nothing is deleted silently — "the agent ignores this" is worth knowing.
- An inference is labelled as an inference.
- No secrets, tokens, or credentials.
- Behaviour, not history: `profile.md` says "prefers X", not "asked for X once, then Y".
